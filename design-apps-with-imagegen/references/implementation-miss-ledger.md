# Image-to-implementation miss ledger

Consult relevant rows when diagnosing implementation drift. These are failure patterns, not extra approval or completion gates.

| Failure | Detection and prevention |
| --- | --- |
| Feature inventory replaces composition | Compare dominant region, fold, and visual weight; establish geometry before component polish. |
| Generic cards flatten the signature | Verify the selected defining traits, including asset-dependent details. |
| Preamble buries the task | Measure where the primary action or reader begins; compact surrounding metadata. |
| Real content changes geometry | Try long titles and dense lists early; define measures, truncation, and disclosure. |
| Wrapping replaces responsive design | Specify what collapses, scrolls, or moves at composition-changing breakpoints. |
| Mobile shrinks desktop | Recompose rails and inspectors; check the primary task remains easy to reach. |
| Split-screen gets phone assumptions | Inspect intermediate widths when panels or navigation change there. |
| Detached chrome strands users | Retain applicable shared navigation and account access through recovery states. |
| Default state differs from the mock | Record the selected initial tab, expansion, and content state. |
| Component styling depends on another feature | Check reusable components load their own required styles. |
| Controls are decorative or capabilities vanish | Map visible controls to real behavior and verify scoped existing capabilities remain reachable. |
| Demo data hides production states | Inspect truthful empty/loading/error states alongside representative populated content. |
| Code-native approximation loses material | Generate actual raster detail when texture or illustration defines the direction; prove one asset at display size. |
| Typography is approximated | Compare family, weight, leading, measure, and wrapping, not just bounding boxes. |
| Sticky regions obscure content | Inspect scroll containers and offsets at affected sizes. |
| Global overflow is misdiagnosed | Measure document, shell, and feature regions separately. |
| Themes break hierarchy | Check supported themes and changed interaction states before final polish. |
| Screenshots are incomparable | Match viewport, scale, content, and expanded state. |
| First screenshot ends critique | Inspect material deltas; correct them when present rather than requiring an arbitrary extra pass. |
| Adaptations hide unfinished work | Explain remaining deviations with constraints or usability evidence. |
| Preview plumbing leaks into source | Remove temporary fixtures, proxies, and debug changes before handoff. |

When a new reusable failure emerges, optionally propose a detection/prevention row in the handoff. Edit the ledger only in a separately authorized skill update; merge overlapping lessons.

# Open collaboration baseline

Use this as the target state when the user asks for the Latent Space baseline or a similar autonomy-first small-company Workspace setup. Replace organization names with the verified tenant name.

Only change deltas. Do not treat this list as permission to widen a different organization's sharing without explicit authorization.

## Directory and profiles

- Allow users to edit name, name pronunciation, profile picture, gender, pronouns, birthday, introduction, work location, other personal information, and profile discovery.
- Enable contact sharing, show all email addresses, and include domain profiles plus shared contacts.

## Drive and Docs

- Set the general-access default for new items to the primary target audience so organization members can search for and find them.
- Allow anyone to distribute content outside the organization, including moving or uploading content into shared drives owned by other organizations.

## Calendar

- Set primary-calendar external sharing to `Share all information, and allow managing of calendars`.
- For each user who wants collaborative events by default: Calendar > Settings > Event settings > Guest permissions > enable `Modify event`.

## Google Chat

- Automatically accept invitations between users in the organization.

## Groups for Business

- Keep organization-wide group access private; do not use `Public on the internet`.
- Do not allow group owners to add external members.
- Allow group owners to accept incoming email from outside the organization.
- Default conversation visibility to group members, not anyone on the internet.
- Allow owners to hide individual groups from the directory, without hiding every newly created group by default.

## Google Meet

- Allow users to receive calls from anyone.
- Set the default meeting access type to `Open`.
- Keep Host management off by default so presentation locking is not enabled.
- Enable screen sharing for organization users.
- Annotation is controlled in the meeting: the presenter appoints co-annotators.

## Gmail

- Enable mailbox delegation and delegation to internal Google Groups; retain user control over sender display.
- Enable Gmail web offline without forcing deletion of offline data at sign-out.
- Allow read receipts to any email address while prompting the user for every request.
- Enable per-user outbound gateways for user-configured external From addresses.

## Preserve

- MFA, spam, malware, phishing, external-recipient warnings, external-participant labels, and administrator safeguards.
- Existing open settings that already match the requested outcome; report them but do not rewrite them.
